# 日本語 단어장

업무·일상 일본어 단어를 복습 간격(1→3→7→14→30일)에 맞춰 외우는 웹앱이에요. 폰·아이패드에서 링크로 열고 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

- 설치나 로그인이 필요 없어요. 공부 기록은 각자의 기기(브라우저)에만 저장돼요.
- 인터넷이 없어도 열려요(한 번 열어 둔 뒤).
- 자동 채우기·예문 만들기·SJPT 질문·상황 대화 만들기는 **설정 → Claude 연결**에 본인 Anthropic API 키를 넣으면 켜져요(선택).
- 다른 기기로 옮기기: **설정 → 전체 데이터 내보내기** 후 다른 기기에서 **가져오기**.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체(화면·기능·내장 단어 319개) |
| `manifest.webmanifest`, `icons/` | 홈 화면 설치용 정보와 아이콘 |
| `sw.js` | 오프라인용 서비스 워커 |

## 고친 뒤 올리기

`index.html`을 고쳐서 올리면 다음에 열 때 자동으로 새 버전이 보여요. 아이콘 등 다른 파일을 바꿨다면 `sw.js`의 `VERSION`도 올려 주세요.
